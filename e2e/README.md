# Сквозная проверка (Playwright)

Проходит сайт как хозяин, гость и админ: регистрация → мастер объявления (фото, цены, номер, удобства, контакты) →
публикация → заявка гостя → подтверждение и переписка → предоплата и выезд → отзыв → модерация → поиск по датам.

Запускается на сервере и ходит на `http://127.0.0.1`. Тестовые аккаунты — `e2e-*@example.test`, пароли генерируются.

```bash
mkdir -p /opt/e2e && cp /opt/renta/e2e/run.mjs /opt/e2e/ && cd /opt/e2e
echo '{"type":"module","private":true}' > package.json
npm i playwright@1 && npx playwright install --with-deps chromium
node run.mjs            # отчёт и скриншоты: /opt/e2e/out
```

После прогона удалите тестовые данные (пользователи `e2e-%@example.test`, их объявления и заявки).
